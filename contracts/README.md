# 전자 계약서

종이 계약서 없이 **모바일 전자 계약서**로 회원을 등록합니다.\
회원은 카카오톡으로 받은 링크를 눌러 휴대폰 브라우저에서 바로 서명합니다. 앱 설치는 필요 없습니다.

---

## 전체 흐름

```
관장 서명 등록 → 계약서 양식 만들기 → 회원권에 연결 → 회원 등록·재등록 때 보내기 → 회원 서명 → 결제 기록
```

계약서는 **체육관 설정 → 계약서**에서 관리합니다.

| 항목 | 하는 일 | 바로가기 |
|---|---|---|
| **계약서 양식** | 체육관 계약서 만들기 | 이 페이지 |
| **관장 서명** | 계약서마다 찍히는 관장 서명 등록 | 이 페이지 |
| **서명 완료 계약서** | 서명된 계약서 찾기, PDF 받기 | [서명 완료된 계약서](signed-management.md) |

계약서를 보내는 일은 회원 등록·재등록 화면에서 합니다. → [계약서 보내기](sending.md)

---

## 계약서 양식 만들기

**체육관 설정 → 계약서 → 양식 추가**를 누르면 **종목에 맞는 기본 초안**이 채워집니다.

<div align="left"><figure><img src="../.gitbook/assets/계약서 기본 템플릿 제공.png" alt="계약서 기본 초안" width="563"><figcaption>기본 초안 — 이용약관, 수업 규정, 면책 규정, 개인정보 동의 등</figcaption></figure></div>

### 기본 조항

1. 이용약관 및 준수사항
2. 수업 규정
3. 면책 규정
4. 이용자의 권리와 의무
5. 개인정보 수집 및 이용 동의

내용은 도장에 맞게 고칠 수 있습니다.

### 종목별 추가 조항

| 종목 | 처음부터 들어 있는 조항 | 직접 추가하면 좋은 조항 |
|---|---|---|
| **주짓수** | 기본 조항 5개 | 환불 규정, 사진·영상 동의, 특약사항 |
| **태권도** | 기본 조항 5개(태권도 내용) + **보호자 동의, 차량 이용 동의, 수련 중 부상 및 응급조치 동의, 사진 및 영상 촬영 동의** | 환불 규정, 특약사항 |

양식 편집 화면의 **환불 규정 넣기 · 사진·영상 동의 넣기**로 자주 쓰는 조항을 바로 넣을 수 있습니다. 환불 규정은 초안으로 들어가니 체육관 규정에 맞게 고쳐 주세요.

<div align="left"><figure><img src="../.gitbook/assets/계약서 조항 커스터마이징.png" alt="조항 수정" width="563"><figcaption>조항을 눌러 도장에 맞게 수정</figcaption></figure></div>

- 조항을 추가·수정·삭제할 수 있습니다.
- 위로·아래로 버튼으로 순서를 바꿀 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/계약서 템플릿 저장됨.png" alt="계약서 양식 저장" width="563"><figcaption>저장한 양식을 회원권에 연결하면 바로 보낼 수 있습니다</figcaption></figure></div>

{% hint style="danger" %}
[회원권](../membership-plans.md)에 연결된 양식은 삭제할 수 없습니다.
{% endhint %}
