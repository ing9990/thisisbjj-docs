# 자동 알림톡

자동 알림톡은 정해 둔 때가 되거나 일이 생기면 회원과 보호자에게 저절로 가는 카카오 알림톡이에요. 한 번 켜 두면 관장님이 따로 보낼 필요가 없고, 따로 드는 비용도 없어요.

웹은 **알림톡** → **자동 알림톡** 탭(또는 **체육관 설정** → **자동 알림톡**), 매니저 앱은 ☰ → **알림톡 · 매출** → **자동 알림톡**에서 설정해요.

## 때가 되면 보내는 알림

매일 오전 9시에 조건을 확인하고, 맞는 회원에게 보내요.

| 알림 | 언제 가나요 | 처음 상태 | 날수 기본값 |
|---|---|---|---|
| **곧 끝나는 회원 알림** | 회원권이 끝나기 N일 전 | 켜짐 | 14일 |
| **회원권 만료 당일 알림** | 회원권이 끝나는 날 | 켜짐 | — |
| **오래 안 온 회원 알림** | 이용 중인 회원이 N일 이상 출석하지 않았을 때 | 꺼짐 | 7일 |

**예시**: 곧 끝나는 회원 알림을 7일로 바꾸면, 11월 30일에 끝나는 회원은 11월 23일 오전 9시에 재등록 안내를 받아요.

{% hint style="warning" %}
**오래 안 온 회원 알림**의 날수는 「마지막 출석 뒤 며칠이 지났는지」예요. 매니저 앱에서는 이 알림 아래에도 「만료 N일 전에 보내요」라고 보이고, 날수를 바꾸는 창도 「만료 며칠 전에 보낼까요?」라고 물어요. 문구와 달리 이 숫자는 출석하지 않은 날수로 쓰여요.
{% endhint %}

## 일이 생기면 보내는 알림

| 알림 | 언제 가나요 | 받는 사람 | 처음 상태 |
|---|---|---|---|
| **승급 축하 알림** | [승급식](../disciplines/bjj-ceremonies.md)에서 **승급 실행**을 눌렀을 때 | 승급한 회원 | 켜짐 |
| **키즈부 등원 알림** | 보호자 번호가 있는 회원이 출석했을 때 | 보호자 | 켜짐 |
| **키즈부 하원 알림** | 등·하원 화면에서 하원을 눌렀을 때 | 보호자 | 켜짐 |

## 항상 켜져 있는 알림

끌 수 없어요. 매니저 앱에서는 **그 밖의 알림톡**에 「항상 켜져 있어요」로 보여요.

| 알림 | 언제 가나요 |
|---|---|
| **계약서 서명 요청 발송** | [입관계약서를 보내면](sending.md) 회원에게 서명 링크 |
| **계약서 서명 완료 알림** | 회원이 서명을 마치면 회원에게 |
| **사업자 인증 완료 알림** | [사업자 인증](../new-members/business-verification.md)이 끝나면 관장님께 |

## 켜고 끄기, 날수 바꾸기

1. 자동 알림톡 화면을 열어요.
2. 알림 오른쪽 스위치로 켜거나 꺼요.
3. 날수가 있는 알림은 날수를 바꿔요. 웹은 숫자 칸에 바로 넣고, 매니저 앱은 알림을 눌러 **보내는 날 바꾸기**에서 넣어요. 1~365일까지 돼요.
4. 바로 저장돼요.

| 하고 싶은 것 | 이렇게 해요 |
|---|---|
| 재등록 늘리기 | 곧 끝나는 회원 알림을 7~14일로 켜 두기 |
| 쉬는 회원 다시 부르기 | 오래 안 온 회원 알림 켜기 |
| 키즈부 학부모 안심 | 등원·하원 알림 켜 두기 |

## 보낸 기록 보기

보낸 알림톡은 웹 **알림톡** → **보낸 기록**, 매니저 앱 ☰ → **발송 내역**에 모여요. 한 회원에게 간 알림톡은 회원 상세의 **알림톡** 칸에서 봐요.

{% hint style="info" %}
곧 끝나는 회원에게 지금 바로 안내하고 싶다면 홈의 **재등록 안내 보내기**를 써요. → [곧 끝나는 회원·오래 안 온 회원](../members/expiring.md)
{% endhint %}
