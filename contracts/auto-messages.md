# 자동 알림톡

정해 둔 때가 되거나 일이 생기면 회원과 보호자에게 저절로 가는 카카오 알림톡이에요. 따로 드는 비용은 없어요.

**이렇게 해요**

1. 매니저 앱 ☰ 에서 **알림톡 · 매출**, **자동 알림톡**을 열어요. 웹은 **알림톡** 메뉴의 **자동 알림톡** 탭이에요.
2. 알림 오른쪽 스위치로 켜거나 꺼요. 바로 저장돼요.
3. 날수가 있는 알림은 알림을 눌러 **보내는 날 바꾸기**에서 1일부터 365일까지 넣어요. 웹은 숫자 칸에 바로 넣어요.

## 때가 되면 보내는 알림

매일 오전 9시에 확인해서 보내요.

| 알림 | 언제 가나요 | 처음 상태 |
|---|---|---|
| **곧 끝나는 회원 알림** | 회원권이 끝나기 N일 전 (기본 14일) | 켜짐 |
| **회원권 만료 당일 알림** | 회원권이 끝나는 날 | 켜짐 |
| **오래 안 온 회원 알림** | N일 이상 출석하지 않았을 때 (기본 7일) | 꺼짐 |

{% hint style="warning" %}
매니저 앱은 **오래 안 온 회원 알림**에도 만료 며칠 전이라고 보여 줘요. 실제로는 마지막 출석 뒤 지난 날수로 쓰여요.
{% endhint %}

## 일이 생기면 보내는 알림

처음엔 모두 켜져 있어요.

| 알림 | 언제 가나요 | 받는 사람 |
|---|---|---|
| **승급 축하 알림** | [승급식](../disciplines/bjj-ceremonies.md)에서 **승급 실행**을 눌렀을 때 | 승급한 회원 |
| **키즈부 등원 알림** | 보호자 번호가 있는 회원이 출석했을 때 | 보호자 |
| **키즈부 하원 알림** | 등하원 화면에서 하원을 눌렀을 때 | 보호자 |

## 끌 수 없는 알림

- **계약서 서명 요청 발송**: [입관계약서를 보내면](sending.md) 회원에게
- **계약서 서명 완료 알림**: 회원이 서명을 마치면 회원에게
- **사업자 인증 완료 알림**: [사업자 인증](../new-members/business-verification.md)이 끝나면 관장님께

## 보낸 기록

매니저 앱 ☰ 의 **발송 내역**에 모여요. 웹은 **알림톡** 메뉴의 **보낸 기록**이에요. 한 회원에게 간 것은 회원 상세 **알림톡** 칸에서 봐요.

곧 끝나는 회원에게 지금 바로 안내하려면 [곧 끝나는 회원](../members/expiring.md)을 보세요.
