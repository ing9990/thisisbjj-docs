# 자동 메시지

미리 켜 두면 조건에 맞는 회원에게 **자동으로 알림**이 갑니다.\
**계약 · 메시지 → 카톡 · 문자 → 자동 메시지**에서 설정합니다.

---

## 스케줄 기반 알림

매일 **오전 9시**에 조건을 확인하고 대상 회원에게 보냅니다. 같은 회원권에는 한 번만 갑니다.

| 알림 | 설명 | 기본값 | 설정 |
|---|---|---|---|
| **회원권 만료 임박 알림** | 만료 N일 전에 갱신 안내 | 꺼짐 | 기준 일수 (기본 14일) |
| **회원권 만료 당일 알림** | 만료되는 날 안내 | 꺼짐 | — |

## 이벤트 기반 알림

일이 생기면 **바로** 보냅니다.

| 알림 | 설명 | 기본값 |
|---|---|---|
| **승급 축하 알림** | [승급식](../jiujitsu/ceremonies.md) · [승급 심사](../taekwondo/promotion-test.md)를 실행하면 승급한 회원에게 축하 메시지 | 켜짐 |
| **키즈부 등원 알림** | 키즈부 회원이 출석하면 보호자에게 | 켜짐 |
| **키즈부 하원 알림** | 등·하원 화면에서 하원을 누르면 보호자에게 | 켜짐 |

{% hint style="info" %}
**준비 중인 알림** — 승급 축하 알림은 카카오 알림톡 심사가 끝나면 발송이 시작됩니다.\
키즈부 등원·하원 알림은 심사가 끝날 때까지 **문자**로 대신 나갑니다.
{% endhint %}

## 항상 켜진 알림

끌 수 없는 알림입니다.

| 알림 | 설명 |
|---|---|
| 계약서 서명 요청 발송 | [계약서 보내기](../contracts/sending.md)를 하면 회원에게 서명 링크 |
| 계약서 체결 완료 알림 | 회원이 서명을 마치면 |
| 사업자 인증 완료 알림 | [사업자 인증](../getting-started/business-verification.md)이 끝나면 관장님께 |

## 설정 방법

1. 알림마다 있는 **켜기/끄기** 스위치를 누릅니다.
2. 기준 일수가 있는 알림은 도장에 맞게 바꿉니다.
3. 바로 적용됩니다.

## 활용 예시

| 상황 | 추천 설정 |
|---|---|
| 재등록 늘리기 | 만료 임박 알림 켜기 (7~14일) |
| 키즈부 학부모 안심 | 등원·하원 알림 켜 두기 |
| 승급 분위기 띄우기 | 승급 축하 알림 켜 두기 |

## 발송 내역

보낸 알림은 **카톡 · 문자 → 발송 내역**과 [회원 상세](../members/detail.md)의 **메세지 이력**에서 확인합니다.
