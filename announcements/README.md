# 카톡 · 문자

회원과 보호자에게 가는 **카카오 알림톡과 문자**를 관리합니다.

---

## 메뉴

| 메뉴 | 설명 |
|---|---|
| **자동 메시지** | 조건이 되면 자동으로 나가는 알림 켜기·끄기 → [자동 메시지](auto-messages.md) |
| **발송 내역** | 지금까지 보낸 알림톡·문자 기록 |

## 자동 메시지 한눈에 보기

| 알림 | 언제 |
|---|---|
| 회원권 만료 임박 알림 | 만료 N일 전 |
| 회원권 만료 당일 알림 | 만료되는 날 |
| 승급 축하 알림 | 승급식·승급 심사를 실행했을 때 |
| 키즈부 등원 · 하원 알림 | 아이가 출석·하원할 때 |
| 계약서 서명 요청 · 체결 완료 | 계약서를 보내고 서명했을 때 (항상 켜짐) |

## 직접 보내기

회원 목록에서 **만료 임박** 필터를 켜면 해당 회원에게 갱신 안내 알림톡을 한 번에 보낼 수 있습니다. → [회원 관리](../members/README.md)

{% hint style="info" %}
회원 한 명 한 명에게 보낸 내역은 [회원 상세](../members/detail.md)의 **메세지 이력**에서도 볼 수 있습니다.
{% endhint %}
