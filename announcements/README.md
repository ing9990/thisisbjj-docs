# 알림톡

회원과 보호자에게 가는 **카카오 알림톡**을 관리합니다.\
메뉴의 **알림톡**에서 확인합니다. 알림톡은 따로 드는 비용이 없습니다.

---

## 탭

| 탭 | 설명 |
|---|---|
| **보낸 기록** | 지금까지 보낸 알림톡과 받은 인원·실패 수 |
| **자동 알림톡** | 조건이 되면 자동으로 나가는 알림톡 켜기·끄기 → [자동 알림톡](auto-messages.md) |

## 자동 알림톡 한눈에 보기

| 알림 | 언제 |
|---|---|
| 곧 끝나는 회원 알림 | 회원권 만료 N일 전 |
| 회원권 만료 당일 알림 | 만료되는 날 |
| 오래 안 온 회원 알림 | N일 이상 출석하지 않았을 때 |
| 승급 축하 알림 | 승급식을 실행했을 때 |
| 키즈부 등원 · 하원 알림 | 아이가 출석·하원할 때 |
| 계약서 서명 요청 · 서명 완료 | 계약서를 보내고 서명했을 때 (항상 켜짐) |

## 직접 보내기

홈의 **"재등록 안내 보내기"**로 회원권이 곧 끝나는 회원에게 재등록 안내 알림톡을 한 번에 보낼 수 있습니다.\
3일 · 7일 · 14일 · 30일 안에 끝나는 회원 중에서 고르고, 같은 기간 안내를 이미 받은 회원은 빠집니다.

{% hint style="info" %}
회원 한 명에게 보낸 알림톡은 [회원 상세](../members/detail.md)의 **알림톡** 기록에서도 볼 수 있습니다.
{% endhint %}

{% hint style="info" %}
공지는 문자 대신 **주짓주짓 앱** 게시판과 앱 알림으로 보냅니다.
{% endhint %}
