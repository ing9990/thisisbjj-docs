# 띠 설정

태권도 도장에서 쓰는 **띠 이름과 색**을 도장에 맞게 바꿉니다.\
**회원 → 띠 설정** 메뉴에서 설정합니다. (태권도 도장에만 보입니다)

---

## 기본 띠 목록

태권도 도장을 등록하면 아래 띠가 자동으로 준비됩니다.

| 구분 | 띠 |
|---|---|
| **급** | 10급 흰띠 · 9급 흰띠 · 8급 노란띠 · 7급 노란띠 · 6급 초록띠 · 5급 초록띠 · 4급 파란띠 · 3급 파란띠 · 2급 빨간띠 · 1급 빨간띠 |
| **품** (만 15세 미만) | 1품 · 2품 · 3품 · 4품 (빨강/검정 두 색) |
| **단** | 1단 ~ 9단 (검정) |

## 띠 바꾸기

띠마다 아래 항목을 바꿀 수 있습니다.

| 항목 | 설명 |
|---|---|
| **이름** | 도장에서 부르는 이름으로 (예: "8급 노란띠" → "8급 주황띠") |
| **색** | 띠 색. **두 색**을 체크하면 품띠처럼 두 가지 색으로 표시 |
| **숨기기** | 도장에서 쓰지 않는 띠를 목록에서 숨김 |

바꾼 뒤 **"저장"**을 누르면 회원 목록, 승급 심사, 대시보드 띠 분포에 바로 반영됩니다.

{% hint style="info" %}
**숨긴 띠**는 새로 고를 수 없지만, 이미 그 띠인 회원은 그대로 유지됩니다.
{% endhint %}

{% hint style="warning" %}
띠를 **새로 추가하거나 순서를 바꾸는 기능은 없습니다.** 기본 목록의 이름·색을 바꾸고, 쓰지 않는 띠는 숨겨서 맞춰 주세요.
{% endhint %}

---

## 회원 띠 정하기

- **한 명씩**: [회원 상세](../members/detail.md)의 수련 정보에서 띠와 설정일을 입력합니다.
- **여러 명을 한 번에**: [승급 심사](promotion-test.md)를 이용하세요.

{% hint style="info" %}
태권도 도장은 키오스크 출석 때 띠를 묻지 않습니다. [회원 데이터 옮기기](../data-migration.md) 후에는 회원 상세나 승급 심사에서 띠를 정해 주세요.
{% endhint %}
