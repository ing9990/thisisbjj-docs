# 승급 심사

태권도 도장의 승급 심사를 관리합니다.\
출석 기준으로 심사 대상자를 뽑고, 검토한 뒤 **한 번에 띠를 올립니다**.\
**회원 → 승급 심사** 메뉴에서 진행합니다.

{% hint style="info" %}
진행 방식은 주짓수 [승급식](../jiujitsu/ceremonies.md)과 같습니다. 이 페이지는 태권도에서 달라지는 점을 중심으로 설명합니다.
{% endhint %}

---

## 진행 순서

```
① 새 승급 심사 만들기 → ② 대상자 검색 → ③ 대상자 검토·조정 → ④ 확정 → ⑤ 일괄 승급 실행
```

### ① 새 승급 심사 만들기

**"새 승급 심사"**를 누르고 아래 항목을 입력합니다.

| 항목 | 예시 |
|---|---|
| 심사 이름 | 2026년 11월 승급 심사 |
| 심사 날짜 | 2026-11-29 |
| 최소 출석일 | 30일 |

회차는 자동으로 붙고, **이전 조건 불러오기**로 지난 심사의 출석 기준을 그대로 쓸 수 있습니다.

### ② 대상자 검색

**"대상자 검색"**을 누르면 최소 출석일을 넘긴 회원이 자동으로 뽑힙니다.\
목록에는 **현재 띠 → 목표 띠**와 출석일이 표시됩니다.

### 목표 띠 자동 제안

다음 띠는 순서대로 자동 제안됩니다. 급에서 품·단으로 넘어갈 때는 **나이**를 봅니다.

| 현재 띠 | 다음 띠 |
|---|---|
| 10급 ~ 2급 | 한 급 위 |
| 1급 | 만 15세 미만은 **1품**, 그 이상은 **1단** |
| 품 | 한 품 위. 만 15세가 넘으면 같은 숫자의 **단**으로 |
| 단 | 한 단 위 |

{% hint style="warning" %}
**나이를 모르는 회원**은 목표 띠를 자동으로 정하지 않습니다. 관장님이 직접 골라 주세요.\
목표 띠가 비어 있는 대상자가 있으면 **"띠를 정해야 하는 대상자가 있습니다"** 안내가 나오고 확정할 수 없습니다.
{% endhint %}

### ③ 대상자 검토·조정

| 기능 | 방법 |
|---|---|
| **목표 띠 바꾸기** | 대상자 행의 ✏️ 버튼 (도장 [띠 설정](ranks.md)에 있는 띠 중에서 선택) |
| **대상자 제외 · 복원** | ✕ 버튼 / 복원 버튼 |
| **회원 직접 추가** | 이름으로 검색해 출석 기준에 못 미친 회원도 추가 |
| **띠 없는 회원** | 경고 영역에서 현재 띠를 먼저 정하기 |

### ④ 확정

**"확정"**을 누르면 대상자 목록이 잠기고 엑셀 다운로드가 가능해집니다. **"확정 취소"**로 다시 고칠 수 있습니다.

### ⑤ 일괄 승급 실행

**"일괄 승급 실행"**을 누르면

1. 모든 대상자의 띠가 목표 띠로 바뀝니다 ("모든 대상자의 띠가 변경되었습니다").
2. 회원별 승급 이력에 기록됩니다.
3. 심사 상태가 **"승급 심사 완료"**로 바뀝니다.
4. [자동 메시지](../announcements/auto-messages.md)의 **승급 축하 알림**이 켜져 있으면 승급한 회원에게 축하 메시지가 갑니다.

{% hint style="danger" %}
실행한 뒤에는 **되돌릴 수 없습니다.** 대상자와 목표 띠를 꼼꼼히 확인하세요.
{% endhint %}

---

## 결과 내보내기

확정·완료된 심사는 **엑셀(.xlsx)**로 내려받을 수 있습니다. 회원 이름, 현재 띠, 목표 띠, 출석일, 상태가 들어 있습니다.

## 자주 묻는 질문

**Q. 국기원 품·단 심사도 여기서 관리하나요?**\
A. 도장 안의 띠 기록을 관리하는 기능입니다. 국기원 심사 결과는 승급 심사나 [회원 상세](../members/detail.md)에서 품·단으로 기록해 두세요.

**Q. 한 명만 띠를 바꾸고 싶어요.**\
A. [회원 상세](../members/detail.md)의 수련 정보에서 바로 바꿀 수 있습니다.
