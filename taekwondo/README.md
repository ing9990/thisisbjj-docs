# 태권도 도장 운영

[도장 등록](../getting-started/gym-registration.md)할 때 **태권도**를 고른 도장에 해당하는 내용입니다.\
회원·회원권·계약서·출석·매출은 [공통 기능](../dashboard.md)과 같고, **띠(급·품·단)와 승급 심사**가 태권도에 맞춰져 있습니다.

---

## 태권도 도장만의 기능

| 기능 | 설명 | 바로가기 |
|---|---|---|
| **급 · 품 · 단 띠 체계** | 10급 흰띠부터 9단까지 기본 띠 목록 제공 | [띠 설정](ranks.md) |
| **띠 설정** | 도장에서 쓰는 띠 이름과 색으로 바꾸기, 안 쓰는 띠 숨기기 | [띠 설정](ranks.md) |
| **승급 심사** | 출석 기준으로 심사 대상자를 뽑아 한 번에 승급, 나이에 맞는 품·단 자동 제안 | [승급 심사](promotion-test.md) |
| **태권도 계약서 초안** | 보호자 동의·차량 이용 동의·부상 응급조치 동의·촬영 동의 포함 | [전자 계약서](../contracts/README.md) |
| **키즈 등·하원** | 아이 등원·하원 알림, 차량 픽업 주소 관리 | [키즈 등·하원](../kids/README.md) |

## 화면에서 달라지는 말

| 주짓수 도장 | 태권도 도장 |
|---|---|
| 벨트 | **띠** |
| 승급식 | **승급 심사** |
| 벨트 분포 | **띠 분포** |
| 그랄 | (표시 안 함) |

- 메뉴 **회원 → 띠 설정**은 태권도 도장에만 보입니다.
- 회원 목록의 **벨트 필터**와 키오스크의 **출석할 때 벨트 고르기**는 태권도 도장에서 나오지 않습니다.

## 처음 운영 준비 순서

1. [띠 설정](ranks.md)에서 도장에서 쓰는 띠 이름·색으로 맞추기
2. **새 계약서 만들기**로 태권도 계약서 초안을 확인하고 회원권에 연결 → [전자 계약서](../contracts/README.md)
3. [회원 데이터 옮기기](../data-migration.md) 또는 [계약서 보내기](../contracts/sending.md)로 회원 등록
4. 키즈부 회원은 [보호자 전화번호](../members/detail.md#보호자-정보)를 넣고 [보호자 주소 링크](../kids/guardian.md)를 학부모 단톡방에 공유
5. 회원 띠는 [회원 상세](../members/detail.md)에서 정하거나, 첫 [승급 심사](promotion-test.md) 때 함께 정하기

{% hint style="success" %}
태권도 계약서 초안에는 **보호자 동의**와 **차량 이용 동의**가 처음부터 들어 있어, 키즈부 운영에 바로 쓸 수 있습니다.
{% endhint %}
