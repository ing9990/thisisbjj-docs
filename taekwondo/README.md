# 태권도 체육관 운영

[체육관 등록](../getting-started/gym-registration.md)할 때 **태권도**를 고른 체육관에 해당하는 내용입니다.\
회원·회원권·계약서·출석·매출은 [공통 기능](../dashboard.md)과 같고, **띠(급·품·단)와 승급식**이 태권도에 맞춰져 있습니다.

---

## 태권도 체육관만의 기능

| 기능 | 설명 | 바로가기 |
|---|---|---|
| **급 · 품 · 단 띠 체계** | 10급 흰띠부터 9단까지 기본 띠 목록 제공 | [띠 설정](ranks.md) |
| **띠 설정** | 체육관에서 쓰는 띠 이름과 색으로 바꾸기, 안 쓰는 띠 숨기기 | [띠 설정](ranks.md) |
| **승급식** | 출석 기준으로 승급 대상자를 뽑아 한 번에 승급, 나이에 맞는 품·단 자동 제안 | [승급식](promotion-test.md) |
| **태권도 계약서 초안** | 보호자 동의·차량 이용 동의·부상 응급조치 동의·촬영 동의 포함 | [전자 계약서](../contracts/README.md) |
| **키즈 등·하원** | 아이 등원·하원 알림, 차량 픽업 주소 관리 | [키즈 등·하원](../kids/README.md) |

## 화면에서 달라지는 말

| 주짓수 체육관 | 태권도 체육관 |
|---|---|
| 벨트 | **띠** |
| 그랄 | (표시 안 함) |
| 승급 나이 기준 | **급·띠 설정** |

여러 명을 한 번에 승급하는 기능은 두 종목 모두 **승급식**이라고 부릅니다.

- **체육관 설정 → 급·띠 설정**은 태권도처럼 급·띠를 쓰는 체육관에만 보입니다.
- 회원 목록의 **벨트 필터**와 키오스크의 **출석할 때 벨트 고르기**는 태권도 체육관에서 나오지 않습니다.

## 처음 운영 준비 순서

1. [띠 설정](ranks.md)에서 체육관에서 쓰는 띠 이름·색으로 맞추기
2. **체육관 설정 → 계약서 → 양식 추가**로 태권도 계약서 초안을 확인하고 회원권에 연결 → [전자 계약서](../contracts/README.md)
3. [엑셀로 회원 등록](../data-migration.md) 또는 [회원 등록](../members/README.md)
4. 키즈부 회원은 [보호자 연락처](../members/detail.md#회원-정보)를 넣고 [보호자 주소 링크](../kids/guardian.md)를 학부모 단톡방에 공유
5. 회원 띠는 [회원 상세](../members/detail.md)에서 정하거나, 첫 [승급식](promotion-test.md) 때 함께 정하기

{% hint style="success" %}
태권도 계약서 초안에는 **보호자 동의**와 **차량 이용 동의**가 처음부터 들어 있어, 키즈부 운영에 바로 쓸 수 있습니다.
{% endhint %}
