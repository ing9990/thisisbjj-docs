# 시작 가이드

회원이 아직 없으면 [홈](../dashboard.md)에 **시작 순서**가 나옵니다.\
"N가지만 하면 출석을 받을 수 있어요" — 세 단계를 차례대로 해 보세요.

---

## 시작 순서

| 순서 | 항목 | 하는 일 | 바로가기 |
|---|---|---|---|
| ① | 회원권 | 1개월, 3개월, 10회권처럼 체육관에서 파는 회원권 만들기 | [회원권 관리](../membership-plans.md) |
| ② | 회원 | 쓰던 명단 파일을 올리거나 한 명씩 등록 | [회원 관리](../members/README.md) · [엑셀로 회원 등록](../data-migration.md) |
| ③ | 첫 출석 | 태블릿에 키오스크를 띄우면 회원이 번호만 눌러 출석 | [출석 키오스크](../attendance/kiosk.md) |

- 지금 할 단계가 펼쳐져 보이고, 끝난 단계에는 체크가 표시됩니다.
- 명단 파일을 올렸다면 운영팀이 확인하는 동안 **"운영팀이 확인하고 있어요"**로 표시됩니다.

{% hint style="info" %}
계약서를 받으려면 **계약서 양식**과 **관장 서명**이 있어야 합니다. 회원 등록 화면에서 바로 만들 수도 있습니다. → [전자 계약서](../contracts/README.md)
{% endhint %}

{% hint style="warning" %}
회원·출석 같은 관리 기능은 **"관리 시작하기"**를 누른 뒤에 열립니다. 누른 날부터 30일 무료입니다. → [구독 관리](../subscription.md)
{% endhint %}

---

## 종목별로 더 준비할 것

- **주짓수 체육관**: 회원 벨트를 한 번에 넣기 어렵다면 키오스크 출석 때 벨트를 고르게 할 수 있습니다. → [벨트 관리](../jiujitsu/belts.md)
- **태권도 체육관**: 체육관에서 쓰는 띠 이름·색을 먼저 맞춰 두세요. → [띠 설정](../taekwondo/ranks.md)
- 사업자 인증은 유료 플랜을 시작하기 전에만 하면 됩니다. → [사업자 인증](business-verification.md)
