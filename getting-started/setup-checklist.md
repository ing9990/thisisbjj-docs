# 시작 가이드

도장을 등록하면 [대시보드](../dashboard.md) 맨 위에 **시작 가이드**가 나타납니다.\
"5분이면 도장 운영 준비가 끝나요" — 다섯 단계를 차례대로 해 보세요.

---

## 시작 가이드 항목

| 순서 | 항목 | 하는 일 | 바로가기 |
|---|---|---|---|
| ① | 회원을 넣어 주세요 | 엑셀이 있으면 한 번에 옮기고, 없으면 계약서를 보내 한 명씩 등록 | [회원 데이터 옮기기](../data-migration.md) |
| ② | 회원권 상품을 만들어 주세요 | 1개월, 3개월, 10회권처럼 도장에서 파는 회원권 | [회원권 관리](../membership-plans.md) |
| ③ | 첫 출석을 찍어 보세요 | 태블릿에 키오스크를 띄우고 번호로 출석 | [출석 키오스크](../attendance/kiosk.md) |
| ④ | 첫 계약서를 보내 보세요 | 회원이 카톡 링크에서 바로 서명 | [계약서 보내기](../contracts/sending.md) |
| ⑤ | 사업자 인증을 해 주세요 | 국세청 정보로 바로 확인 | [사업자 인증](business-verification.md) |

{% hint style="info" %}
④ 계약서를 보내려면 **계약서 양식**이 먼저 있어야 합니다. **전자 계약서 → 계약서 양식 → 새 계약서 만들기**를 누르면 종목에 맞는 기본 초안이 채워집니다. → [전자 계약서](../contracts/README.md)
{% endhint %}

## 진행 상황

- 항목을 끝내면 자동으로 체크되고 **"n / 5 완료"**로 표시됩니다.
- 다섯 개를 모두 끝내면 시작 가이드가 사라집니다.
- **"닫기"**를 누르면 바로 숨길 수 있습니다. 닫으면 **다시 열 수 없으니** 주의하세요.

{% hint style="success" %}
시작 가이드를 다 하지 않아도 매니저의 모든 기능을 쓸 수 있습니다.
{% endhint %}

- **태권도 도장**: 도장에서 쓰는 띠 이름·색을 먼저 맞춰 두세요. → [띠 설정](../taekwondo/ranks.md)
