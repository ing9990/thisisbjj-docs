# 사업자 인증

사업자등록 정보를 **국세청 정보로 바로 확인**해 인증된 도장으로 표시합니다.

---

## 언제 필요한가요?

도장을 새로 등록하면 인증 없이도 매니저의 모든 기능을 쓸 수 있습니다.\
아래 경우에는 사업자 인증이 필요합니다.

| 경우 | 이유 |
|---|---|
| **파트너 플랜** 구독 | 사업자 인증이 끝난 도장만 구독할 수 있습니다. → [구독 관리](../subscription.md) |
| **이미 등록된 도장 가져오기** | 내 도장이 맞는지 확인합니다. → [도장 등록](gym-registration.md) |
| **인증 배지** | 도장 정보에 **"인증된 도장"**으로 표시됩니다. |

## 인증하는 곳

- [도장 정보](../gym-info.md)의 **"미인증 · 사업자 인증하기"**
- [시작 가이드](setup-checklist.md)의 **"사업자 인증을 해 주세요"**

## 입력 항목

사업자등록증에 적힌 **그대로** 입력하세요.

| 항목 | 예시 | 필수 |
|---|---|---|
| 대표자명 | 홍길동 | ✅ |
| 사업자등록번호 | 000-00-00000 | ✅ |
| 개업연월일 | 2024-03-01 | ✅ |
| 연락처 | 010-0000-0000 | ✅ |
| 사업자등록증 | JPG, PNG, PDF (5MB 이하) | 선택 |

**"확인하기"**를 누르면 국세청 정보와 바로 대조합니다.

## 결과

| 결과 | 안내 |
|---|---|
| ✅ **정보 일치 · 계속사업자** | 즉시 인증이 끝나고 **알림톡**으로 안내됩니다. |
| ❌ **휴업 · 폐업** | 인증되지 않습니다. 사업자 상태를 확인해 주세요. |
| ❌ **정보 불일치** | 사업자번호·대표자명·개업일자를 등록증과 똑같이 다시 입력해 주세요. |
| 🕐 **불일치 + 등록증 첨부** | 운영팀이 등록증을 보고 직접 검토합니다. 보통 **영업일 하루** 안에 끝납니다. |

{% hint style="info" %}
국세청 확인이 안 될 때를 대비해 **사업자등록증을 함께 올려 두면** 운영팀 검토로 이어집니다.
{% endhint %}

## 인증 상태 확인

[도장 정보](../gym-info.md) 상단 배지로 확인합니다.

| 배지 | 의미 |
|---|---|
| 인증된 도장 | 인증 완료 |
| 인증 심사중 | 운영팀 검토 중 |
| 미인증 · 사업자 인증하기 | 아직 인증 전 (누르면 인증 화면으로 이동) |
