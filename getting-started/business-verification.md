# 사업자 인증

사업자등록 정보를 **국세청 정보로 바로 확인**해 인증된 체육관으로 표시합니다.

---

## 언제 필요한가요?

체육관을 새로 등록할 때는 인증이 없어도 됩니다.\
아래 경우에는 사업자 인증이 필요합니다.

| 경우 | 이유 |
|---|---|
| **유료 플랜** 구독 | 사업자 인증이 끝난 체육관만 구독할 수 있습니다. → [구독 관리](../subscription.md) |
| **내 체육관 되찾기** | 다른 계정이 먼저 등록한 내 체육관을 넘겨받을 때 확인합니다. → [체육관 등록](gym-registration.md) |
| **인증 표시** | 체육관 정보에 **"인증 완료"**로 표시됩니다. |

## 인증하는 곳

- [체육관 정보](../gym-info.md)의 **"인증하기"**
- [구독](../subscription.md) 화면의 사업자 인증 안내

## 입력 항목

사업자등록증에 적힌 **그대로** 입력하세요.

| 항목 | 예시 | 필수 |
|---|---|---|
| 대표자명 | 홍길동 | ✅ |
| 사업자등록번호 | 000-00-00000 | ✅ |
| 개업연월일 | 2024-03-01 | ✅ |
| 연락처 | 인증한 휴대폰 번호가 미리 채워져요 | ✅ |
| 사업자등록증 | JPG, PNG, WEBP (5MB 이하) | 선택 |

**"보내기"**를 누르면 국세청 정보와 바로 대조합니다.

## 결과

| 결과 | 안내 |
|---|---|
| ✅ **정보 일치 · 계속사업자** | 즉시 인증이 끝나고 **알림톡**으로 안내됩니다. |
| ❌ **휴업 · 폐업** | 인증되지 않습니다. 사업자 상태를 확인해 주세요. |
| ❌ **정보 불일치** | 사업자번호·대표자명·개업일자를 등록증과 똑같이 다시 입력해 주세요. |
| 🕐 **불일치 + 등록증 첨부** | 운영팀이 등록증을 보고 직접 검토합니다. 보통 **영업일 하루** 안에 끝납니다. |

{% hint style="info" %}
국세청 확인이 안 될 때를 대비해 **사업자등록증을 함께 올려 두면** 운영팀 검토로 이어집니다.
{% endhint %}

## 인증 상태 확인

[체육관 정보](../gym-info.md)에서 확인합니다.

| 표시 | 의미 |
|---|---|
| 인증 완료 | 인증이 끝남 |
| 검토 중 | 운영팀이 확인하는 중 |
| 인증 전 | 아직 인증 전 (**"인증하기"**를 누르면 인증 화면으로 이동) |
