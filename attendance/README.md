# 출석 & 키오스크

태블릿이나 PC로 회원 셀프 출석을 받고, 출석 기록을 관리합니다.\
홈의 **오늘 출석**을 누르거나, 휴대폰에서는 **전체 → 출석**으로 들어갑니다.

---

## 출석 화면

| 탭 | 설명 |
|---|---|
| **출석** | 오늘 출석한 회원 확인, 직접 출석 체크 |
| **등·하원** | 키즈부 아이들의 등원·하원 체크와 보호자 알림 → [키즈 등·하원](../kids/README.md) |
| **통계** | 월별 · 요일별 · 시간대별 출석 → [출석 통계](stats.md) |

## 오늘의 출석

- 오늘 출석한 회원 목록과 인원을 확인합니다.
- 출석이 기록되면 **횟수권은 1회 차감**, 기간권은 기록만 남습니다.
- 같은 날 다시 출석하면 "이미 출석했어요"로 안내되고 중복 기록되지 않습니다.

### 직접 출석 체크

출석 키오스크를 못 쓴 회원은 이름이나 전화번호로 찾아 **직접 출석 체크**합니다.\
잘못 넣은 출석은 **출석 취소**로 지웁니다.

{% hint style="info" %}
**키즈부 회원**이 출석하면 보호자에게 **등원 알림**이 자동으로 갑니다. → [키즈 등·하원](../kids/README.md)
{% endhint %}
