# 출석 & 키오스크

태블릿이나 PC로 회원 셀프 출석을 받고, 출석 기록을 관리합니다.

---

## 기능 구성

| 메뉴 | 설명 |
|---|---|
| **출석 관리** | 오늘 출석한 회원 확인, 출석 통계 |
| **출석 키오스크** | 회원이 번호 4자리로 직접 출석 (새 탭으로 열림) → [출석 키오스크](kiosk.md) |
| **등·하원** | 키즈부 아이들의 등원·하원 체크와 보호자 알림 → [키즈 등·하원](../kids/README.md) |

## 오늘의 출석

**오늘 운영 → 출석 관리** 첫 화면입니다.

- 오늘 출석한 회원 목록과 총 출석 수를 확인합니다.
- 출석이 기록되면 **횟수제 회원권은 1회 차감**, 기간제는 기록만 남습니다.
- 같은 날 다시 출석하면 "이미 출석했습니다"로 안내되고 중복 기록되지 않습니다.

{% hint style="info" %}
**키즈부 회원**이 출석하면 보호자에게 **등원 알림**이 자동으로 갑니다. → [키즈 등·하원](../kids/README.md)
{% endhint %}
