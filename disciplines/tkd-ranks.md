# 태권도 띠 설정

태권도 체육관은 급·품·단으로 회원의 띠를 기록해요. 체육관을 등록하면 기본 띠 목록이 자동으로 준비되고, 띠 이름과 색은 체육관에서 부르는 대로 바꿀 수 있어요. 쓰지 않는 띠는 숨겨요.

{% hint style="info" %}
[체육관 등록](../getting-started/gym-registration.md)에서 종목을 **태권도**로 고른 체육관의 내용이에요. 화면에는 「벨트」 대신 **띠**라고 나오고, 그랄은 보이지 않아요.
{% endhint %}

## 기본 띠 목록

| 구분 | 띠 |
|---|---|
| **급** | 10급 흰띠 · 9급 흰띠 · 8급 노란띠 · 7급 노란띠 · 6급 초록띠 · 5급 초록띠 · 4급 파란띠 · 3급 파란띠 · 2급 빨간띠 · 1급 빨간띠 |
| **품** (만 15세 미만) | 1품 · 2품 · 3품 · 4품 (빨강·검정 두 색) |
| **단** | 1단 ~ 9단 (검정) |

## 띠 이름과 색 바꾸기

웹 **체육관 설정** → **급·띠 설정**, 매니저 앱 ☰ → **회원** → **띠 설정**에서 바꿔요.

**예시**: 체육관에서 8급을 주황띠로 쓴다면 「8급 노란띠」를 「8급 주황띠」로 바꾸고 색을 주황으로 골라요.

1. 바꿀 띠를 눌러요.
2. **띠 이름**과 **색**을 바꿔요. **둘째 색**을 고르면 품띠처럼 두 색으로 보여요.
3. **저장**을 눌러요. 회원 목록과 승급식에 바로 반영돼요.

| 하고 싶은 것 | 이렇게 해요 |
|---|---|
| 쓰지 않는 띠 빼기 | **숨기기**. 아래 **숨긴 급·띠**로 옮겨져요 |
| 숨긴 띠 다시 쓰기 | 숨긴 급·띠에서 **다시 넣기** |

{% hint style="info" %}
숨긴 띠는 새로 고를 수 없지만, 이미 그 띠인 회원은 그대로예요.
{% endhint %}

{% hint style="warning" %}
띠를 새로 더하거나 순서를 바꾸는 기능은 없어요. 기본 목록의 이름과 색을 바꾸고, 안 쓰는 띠는 숨겨서 맞춰 주세요.
{% endhint %}

## 회원 띠 정하기

- **한 명씩**: 회원 상세 오른쪽 위 **⋯** → **띠 변경**에서 띠와 승급일을 넣어요. 바꾼 내용은 회원 상세의 **띠 이력**(매니저 앱은 **승급** 칸)에 남아요.
- **여러 명을 한 번에**: [태권도 승급식](tkd-ceremonies.md)을 써요.

{% hint style="info" %}
태권도 체육관은 [출석 키오스크](../attendance/kiosk.md)에서 띠를 묻지 않아요. [회원 옮기기](../getting-started/import-members.md) 뒤에는 회원 상세나 첫 승급식에서 띠를 정해 주세요.
{% endhint %}

## 태권도 입관계약서

태권도 체육관이 계약서 양식을 새로 만들면 기본 조항 5개에 **보호자 동의, 차량 이용 동의, 수련 중 부상 및 응급조치 동의, 사진 및 영상 촬영 동의**가 처음부터 들어 있어요. 키즈부 운영에 바로 쓸 수 있어요. → [계약서 양식 고치기](../contracts/templates.md)

## 유도·그 외 종목

유도와 「그 외」로 등록한 체육관도 같은 **급·띠 설정**을 써요. 기본 띠는 흰띠 · 노란띠 · 주황띠 · 초록띠 · 파란띠 · 갈색띠 · 검은띠예요. 이름과 색을 종목에 맞게 바꾸고, 안 쓰는 띠는 숨겨서 써요.
