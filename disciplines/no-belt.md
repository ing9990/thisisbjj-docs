# 띠 없는 종목 (MMA·복싱 등)

MMA, 복싱, 무에타이, 킥복싱, 레슬링처럼 띠가 없는 종목으로 등록한 체육관은 벨트·띠 화면이 모두 빠진 채로 주짓주짓 매니저를 써요. 회원, 회원권, 출석, 입관계약서, 결제 기록, 매출, 공지, 체육관 페이지는 다른 종목과 똑같이 써요.

## 어떤 종목이 띠 없이 쓰나요

| 종목 | 띠 |
|---|---|
| **MMA · 복싱 · 무에타이 · 킥복싱 · 레슬링** | 띠 없음 (이 페이지) |
| **주짓수** | IBJJF 벨트와 그랄 → [주짓수 벨트와 그랄](bjj-belts.md) |
| **태권도** | 급·품·단 → [태권도 띠 설정](tkd-ranks.md) |
| **유도 · 그 외** | 체육관이 이름·색을 바꾸는 띠 → [태권도 띠 설정](tkd-ranks.md) |

종목은 [체육관 등록](../getting-started/gym-registration.md)할 때 골라요.

## 화면에서 빠지는 것

**예시**: 복싱 체육관은 회원 목록에 이름, 회원권, 끝나는 날만 보여요. 벨트 색 줄이나 「승급 대상」 줄은 나오지 않아요.

| 빠지는 것 | 띠를 쓰는 종목에서는 |
|---|---|
| 회원 목록·회원 상세의 벨트 표시와 승급 기록 | 이름 옆 벨트, 회원 상세 「승급」 칸 |
| 회원 상세 ⋯ 메뉴의 **벨트 변경** | 한 명씩 벨트 바꾸기 |
| **승급식** 메뉴와 홈·회원 탭의 승급 대상 알림 | 여러 명을 한 번에 승급 |
| 체육관 설정의 **출석할 때 벨트 설정**, **급·띠 설정**, **승급 나이 기준** | 띠와 승급 기준 설정 |
| 회원 등록 때 벨트 고르기 | 첫 벨트 정하기 |

[출석 키오스크](../attendance/kiosk.md)도 띠를 묻지 않고, 전화번호 뒷 4자리만 누르면 출석돼요.

## 입관계약서 기본 조항

계약서 양식을 새로 만들면 기본 5개 조항이 종목에 맞는 말로 들어가요. 띠 없는 종목은 **승급 조항이 빠져** 있어요.

- 「도복(기) 또는 래쉬가드·쇼츠」 → 「도복 또는 운동복」
- 「상대방의 탭(항복 신호)을 존중」 → 「상대방의 중단 신호를 존중」
- 「벨트 승급은 지도자의 재량에 따르며…」 조항 → 없음

체육관 규칙에 맞게 더 고치려면 [계약서 양식 고치기](../contracts/templates.md)를 보세요.
