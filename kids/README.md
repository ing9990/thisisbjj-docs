# 키즈 등·하원

키즈부 아이가 도장에 오면 **등원**, 집에 가면 **하원** 알림이 보호자에게 갑니다.\
차량 픽업 주소도 한 화면에서 관리합니다. 주짓수·태권도 도장 모두 쓸 수 있습니다.

---

## 키즈부 회원 만들기

[회원 상세](../members/detail.md)에 **보호자 전화번호**가 들어 있는 회원은 모두 **키즈부 회원**입니다.

- 직접 입력: 회원 상세 → **보호자 성명 · 보호자 전화번호**
- 자동 입력: 미성년자가 [계약서에 서명](../contracts/signing-flow.md)하면 보호자 정보가 채워집니다.

## 알림이 가는 때

| 알림 | 언제 | 받는 사람 |
|---|---|---|
| **등원 알림** | 아이가 출석할 때 (키오스크, 출석 관리, 등·하원 화면의 **"등원"** 버튼) | 보호자 번호 |
| **하원 알림** | 등·하원 화면에서 **"하원"** 버튼을 누를 때 | 보호자 번호 |

보호자가 받는 메시지 예시:

```
[주짓주짓] 김하늘 학생이 OO도장에 등원했어요.
등원 시각: 오후 3:05
```

{% hint style="info" %}
- 같은 날 두 번 출석해도 등원 알림은 **한 번만** 갑니다.
- 지금은 **문자**로 발송되며, 카카오 알림톡 심사가 끝나면 자동으로 알림톡으로 바뀝니다.
- 알림을 끄려면 [자동 메시지](../announcements/auto-messages.md)에서 **키즈부 등원 알림 / 키즈부 하원 알림**을 끄세요. (기본 켜짐)
{% endhint %}

## 등·하원 화면

**오늘 운영 → 등·하원** (휴대폰은 아래 탭의 **등·하원**)에서 엽니다. 차량을 운행하는 사범님이 휴대폰으로 쓰기 좋습니다.

상단에 오늘 날짜와 **등원 n / 전체**, **하원 n**이 표시됩니다.

### 탭

| 탭 | 설명 |
|---|---|
| **등원 픽업** | 오늘 데리러 갈 아이들 |
| **하원** | 등원한 아이부터, **같은 주소끼리 묶어서** 보여 줍니다 |

### 아이 카드

| 표시 | 설명 |
|---|---|
| 이름 · 보호자 | 아이 이름과 보호자 이름 |
| 상태 | 등원 전 / 등원 HH:mm / 하원 HH:mm |
| 주소 · 메모 | 픽업 주소, 하원 주소, 보호자가 남긴 말 |

| 버튼 | 하는 일 |
|---|---|
| **전화** | 보호자에게 바로 전화 |
| **지도** | 카카오맵으로 주소 열기 |
| **등원** | 출석 기록 + 등원 알림 |
| **하원** | 하원 기록 + 하원 알림 |
| **되돌리기** | 잘못 누른 등원·하원 취소 |
| **주소 고치기** | 픽업 주소 / 하원 주소 / 메모 수정 |

{% hint style="warning" %}
**등원 되돌리기**를 하면 출석이 취소되고 횟수권은 1회가 돌아옵니다. 하지만 이미 보낸 알림은 취소되지 않습니다.
{% endhint %}

## 보호자에게 주소 받기

화면 아래 **보호자 주소 입력 링크**를 **"복사"**해서 학부모 단톡방에 올려 주세요.\
보호자가 휴대폰 인증 후 우리 아이 주소를 직접 넣습니다. → [보호자 주소 입력](guardian.md)

- **"새 링크 만들기"**를 누르면 예전 링크는 더 이상 열리지 않습니다.
- 키즈부 회원이 없으면 "키즈부 회원이 아직 없어요"가 보입니다. 회원 정보에 보호자 연락처를 먼저 넣어 주세요.
