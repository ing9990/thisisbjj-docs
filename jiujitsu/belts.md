# 벨트 관리

주짓수 체육관 회원의 벨트를 관리합니다.\
한 명씩 승급하거나 이력을 보는 건 [회원 상세](../members/detail.md)에서, 여러 명을 한 번에 승급하는 건 [승급식](ceremonies.md)에서 합니다.

---

## 벨트 체계

IBJJF 기준을 따릅니다. 벨트 목록은 바꿀 수 없습니다.

| 구분 | 벨트 | 단계 |
|---|---|---|
| **키즈** | 그레이·화이트 → 그레이 → 그레이·블랙 → 옐로·화이트 → 옐로 → 옐로·블랙 → 오렌지·화이트 → 오렌지 → 오렌지·블랙 → 그린·화이트 → 그린 → 그린·블랙 벨트 | 각 0~4그랄 |
| **성인** | 화이트 → 블루 → 퍼플 → 브라운 벨트 | 각 0~4그랄 |
| **블랙** | 블랙 벨트 | 무단 · 1~6단 |
| **마스터** | 레드·블랙 벨트 (7단) → 레드·화이트 벨트 (8단) → 레드 벨트 (9단) | — |

화면에는 "블루 벨트 2그랄", "블랙 벨트 3단"처럼 표시됩니다.

{% hint style="info" %}
블랙 벨트의 단은 저장하고 보여 주지만, [승급식](ceremonies.md)에서 블랙 벨트 이상 회원을 승급 대상으로 추천하지는 않습니다. 직접 넣는 것은 됩니다.
{% endhint %}

## 한 명씩 승급하기

[회원 상세](../members/detail.md)의 **승급** 칸에서 벨트를 바꿉니다.

- 승급 날짜와 메모를 남길 수 있습니다 (예: "2026 상반기 승급식").
- 바꾼 내용은 **승급 이력**에 쌓입니다.
- 잘못 넣은 기록은 승급 이력에서 지울 수 있습니다.

## 승급 이력

| 항목 | 설명 |
|---|---|
| 이전 벨트 → 새 벨트 | 어떤 벨트에서 어떤 벨트로 |
| 승급일 | 벨트가 바뀐 날 |
| 승급자 | 누가 승급시켰는지 |
| 메모 | 승급 때 남긴 메모 |

## 출석할 때 벨트 고르기

[엑셀로 회원 등록](../data-migration.md)이나 신규 등록 뒤에는 벨트가 비어 있는 회원이 많습니다.\
**체육관 설정 → 출석할 때 벨트 설정**이 켜져 있으면(기본 켜짐), 벨트가 없는 회원이 [키오스크](../attendance/kiosk.md)로 출석할 때 **한 번만** 벨트를 고르게 합니다.

<div align="left"><figure><img src="../.gitbook/assets/출석체크와 벨트선택.gif" alt="출석할 때 벨트 고르기" width="563"><figcaption>출석 → 주니어/시니어 → 벨트 색 → 그랄 → 완료</figcaption></figure></div>

1. "벨트가 설정되지 않았어요." → **주니어 / 시니어** 선택
2. "벨트 색상을 선택해주세요." → 벨트 선택
3. "그랄을 선택해주세요." → 그랄 선택
4. "감사합니다." → 출석 완료

- 이미 벨트가 있는 회원에게는 나오지 않습니다.
- 회원이 고른 벨트가 틀리면 [회원 상세](../members/detail.md)에서 고쳐 주세요.

---

## 여러 명을 한 번에

출석 기준으로 대상자를 뽑아 한 번에 승급하려면 [승급식](ceremonies.md)을 이용하세요.
