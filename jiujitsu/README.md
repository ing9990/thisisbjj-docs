# 주짓수 도장 운영

[도장 등록](../getting-started/gym-registration.md)할 때 **주짓수**를 고른 도장에 해당하는 내용입니다.\
회원·회원권·계약서·출석·매출은 [공통 기능](../dashboard.md)과 같고, **벨트와 승급식**이 주짓수에 맞춰져 있습니다.

---

## 주짓수 도장만의 기능

| 기능 | 설명 | 바로가기 |
|---|---|---|
| **IBJJF 벨트 체계** | 유소년 벨트, 성인 벨트(그랄 0~4), 블랙벨트 단, 마스터 벨트 | [벨트 관리](belts.md) |
| **출석할 때 벨트 고르기** | 벨트가 없는 회원이 키오스크에서 1회만 벨트를 직접 고름 | [벨트 관리](belts.md#출석할-때-벨트-고르기) |
| **승급식** | 출석 기준으로 승급 대상자를 뽑아 한 번에 승급 | [승급식](ceremonies.md) |
| **벨트 필터 · 벨트 분포** | 회원 목록 벨트 필터, 대시보드 벨트 분포 | [회원 관리](../members/README.md) |

## 주짓수 계약서 초안

계약서 양식을 새로 만들면 주짓수 도장에 맞는 **기본 조항 5개**가 채워집니다.\
환불 규정, 사진·영상 촬영 동의, 특약사항은 필요에 따라 추가하세요. → [전자 계약서](../contracts/README.md)

## 처음 운영 준비 순서

1. [회원 데이터 옮기기](../data-migration.md) 또는 [계약서 보내기](../contracts/sending.md)로 회원 등록
2. 상단 **설정 → 출석체크로 벨트설정**이 켜져 있는지 확인 (기본 켜짐)
3. [출석 키오스크](../attendance/kiosk.md)를 띄워 두면 회원이 출석하면서 자기 벨트를 고릅니다
4. 출석이 쌓이면 [승급식](ceremonies.md)으로 승급 대상자를 뽑습니다

{% hint style="info" %}
키즈부가 있다면 [키즈 등·하원](../kids/README.md)도 함께 써 보세요. 아이가 출석하면 보호자에게 등원 알림이 갑니다.
{% endhint %}
