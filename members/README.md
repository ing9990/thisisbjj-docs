# 회원 관리

체육관의 모든 회원을 찾고 관리합니다.\
메뉴의 **회원**에서 확인합니다.

---

## 회원은 어떻게 등록하나요?

**회원 → 회원 등록**을 누르면 두 가지 중에서 고릅니다.

| 고르기 | 언제 | 하는 일 |
|---|---|---|
| **오늘 처음 온 회원** | 새 회원 | 회원권을 고르고 결제를 기록한 뒤 계약서까지 받습니다. |
| **이미 다니던 회원** | 원래 다니던 회원을 옮길 때 | 쓰던 회원권과 남은 기간(횟수)만 넣습니다. 계약서는 재등록할 때 받습니다. |

회원이 많다면 쓰던 명단 파일을 올려 주세요. 운영팀이 등록해 드립니다. → [엑셀로 회원 등록](../data-migration.md)

### 오늘 처음 온 회원

1. 이름과 휴대폰 번호를 넣습니다. 미성년자는 보호자 이름과 번호로 등록합니다.
2. 회원권과 시작일을 고릅니다.
3. **"결제는 받으셨나요?"** — 받았다면 받은 날과 결제 수단(카드 · 현금 · 계좌이체)을 기록합니다. 아직이면 나중에 기록해도 됩니다.
4. 계약서를 어떻게 받을지 고릅니다.
   - **카카오톡으로 보내기**: 회원(미성년자는 보호자) 번호로 서명 링크가 갑니다.
   - **지금 여기서 서명**: 회원 휴대폰으로 QR을 찍어 바로 서명합니다.
   - **이번엔 계약서 없이**: 재등록할 때 받습니다.

{% hint style="info" %}
결제는 체육관에서 쓰던 방식(카드 단말기, 계좌이체 등)대로 받고, 주짓주짓 매니저에는 **기록만** 남깁니다.
{% endhint %}

### 이미 다니던 회원

- **기간권**은 **시작한 날**만 고릅니다. 끝나는 날은 회원권 일수로 자동 계산됩니다.
- **횟수권**은 **남은 횟수**만 넣습니다.

## 회원 목록

### 찾기

이름이나 전화번호로 찾습니다. 없는 회원이면 그 자리에서 바로 새로 등록할 수 있습니다.

### 조건으로 좁히기

| 묶음 | 예시 |
|---|---|
| 할 일 · 상태 | 결제 전, 계약 진행, 곧 끝나는 회원, 오래 안 온 회원, 횟수 얼마 안 남음, 회원권 없는 회원 |
| 회원권 종류 | 기간권 · 횟수권 |
| 연령 | 키즈 · 성인 |
| 벨트 | 벨트 색 (**벨트·띠가 있는 종목만**) |

정렬은 가나다 순, 만료일 순, 최근 출석 순, 나이 순, 벨트 순으로 바꿀 수 있습니다.

### 곧 끝나는 회원에게 알림톡 보내기

홈의 **"재등록 안내 보내기"**로 회원권이 곧 끝나는 회원에게 재등록 안내 알림톡을 한 번에 보냅니다. 이미 같은 안내를 받은 회원은 자동으로 빠집니다. → [알림톡](../announcements/README.md)
