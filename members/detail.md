# 회원 상세

회원 목록에서 회원을 누르면 상세 화면으로 이동합니다.\
한 화면에서 회원 정보, 회원권, 결제, 계약서, 출석, 승급, 메모를 관리합니다.

---

## 회원 정보

**"정보 수정"**으로 고칩니다.

| 항목 | 설명 |
|---|---|
| 이름 | 회원 이름 |
| 연락처 | 휴대폰 번호 (키오스크 출석에 사용) |
| 생년월일 · 나이 | 승급 추천과 연령 조건에 쓰입니다 |
| 등록일 | 체육관에 등록된 날 |
| 운동 시작일 | 직접 입력 |
| 건강 주의사항 | 수업 때 참고할 정보 |
| 보호자 이름 · 보호자 연락처 | 미성년 회원의 보호자 |

{% hint style="success" %}
**보호자 연락처**를 넣으면 그 회원은 **키즈부 회원**이 되어 [등·하원](../kids/README.md) 화면에 나오고, 출석할 때 보호자에게 등원 알림이 갑니다.\
미성년자가 계약서에 서명하면 보호자 정보가 자동으로 채워집니다.
{% endhint %}

## 회원권

- **기간권**: 끝나는 날, 남은 기간
- **횟수권**: 남은 횟수
- 이번 달 출석 달력도 함께 봅니다.

### 재등록

**"재등록"**을 누르고 회원권을 고르면 새 회원권이 시작됩니다.

1. 결제를 받았다면 받은 날과 결제 수단을 기록합니다. 기록한 결제는 [매출](../settlement.md)에 잡힙니다.
2. 계약서는 **카카오톡으로 보내기**, **지금 여기서 서명**(QR), **이번엔 계약서 없이** 중에서 고릅니다. 회원권과 가격이 같으면 지난 계약서로 진행할 수도 있습니다.

{% hint style="warning" %}
재등록하려면 [회원권](../membership-plans.md)이 1개 이상 있어야 합니다.
{% endhint %}

### 결제 기록 · 환불 · 횟수 고치기

- **결제 기록**: 아직 결제 전인 회원권에 받은 결제를 기록합니다. 잘못 넣은 기록은 **기록 취소**로 지웁니다.
- **환불**: 사용한 기간·횟수에 따라 **권장 환불 금액**이 계산됩니다. 환불 금액과 사유를 기록합니다.
- **횟수 고치기**: 횟수권의 남은 횟수를 늘리거나 줄입니다. 고친 기록이 남습니다.

## 계약서

회원권마다 **계약서 보기**로 서명한 계약서를 엽니다. 서명을 기다리는 링크는 **다시 보내기 · 링크 복사 · 링크 취소**를 할 수 있습니다.

## 승급

현재 벨트·띠와 승급 이력을 봅니다. 벨트·띠는 여기서 한 명씩 바꿀 수 있습니다.\
→ [벨트 관리 (주짓수)](../jiujitsu/belts.md) · [승급식](../jiujitsu/ceremonies.md)

## 알림톡

이 회원에게 보낸 알림톡 기록입니다. → [자동 알림톡](../announcements/auto-messages.md)

## 관장 메모

회원에게는 보이지 않는 **내부 메모**입니다. 부상 이력, 특이 사항 등을 기록하세요.
