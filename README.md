# 주짓주짓 매니저 이용 가이드

주짓주짓 매니저는 격투기 체육관 관장님을 위한 서비스예요. 체육관을 등록하면 주짓주짓 앱에서 근처 체육관을 찾는 사람에게 보이고, 체험 신청을 받아요. 회원·출석·입관계약서·승급식 관리는 「관리 시작하기」를 누르면 열려요.

## 처음 30분 안에 시작하기

위에서부터 차례대로 하면 돼요. 1~3단계는 계속 무료예요.

{% stepper %}
{% step %}
### 가입하기 · 약 10초

휴대폰 번호, 또는 카카오·네이버·구글 계정으로 가입해요.

→ [가입과 로그인](getting-started/login.md)
{% endstep %}

{% step %}
### 체육관 등록하기 · 약 3분

종목·이름·주소를 넣어요. 등록하면 주짓주짓 앱 근처 찾기에 바로 보여요.

→ [체육관 등록](getting-started/gym-registration.md)
{% endstep %}

{% step %}
### 체육관 페이지 꾸미기

운동 사진, 소개, 시간표, 회비, 문의 방법을 채워요. 체험 받을 수업을 고르면 체험 신청도 받아요.

→ [체육관 페이지 꾸미기](getting-started/gym-page-setup.md)
{% endstep %}

{% step %}
### 관리 시작하기 · 30일 무료

「관리 시작하기」를 누르면 회원·출석·계약서·승급식 관리가 열려요. 30일은 무료예요.

→ [관리 시작하기](getting-started/start-management.md)
{% endstep %}

{% step %}
### 회원 옮기기

쓰던 프로그램에서 받은 엑셀이나 CSV를 올리면 운영팀이 옮겨 드려요. 양식은 맞추지 않아도 돼요.

→ [회원 옮기기](getting-started/import-members.md)
{% endstep %}

{% step %}
### 출석 키오스크 켜기

출입구에 태블릿을 두면 회원이 전화번호 뒷 4자리로 출석해요.

→ [출석 키오스크](attendance/kiosk.md)
{% endstep %}
{% endstepper %}
