# 주짓주짓 매니저 이용 가이드

체육관을 등록하면 주짓주짓 앱 근처 찾기에 보이고 체험 신청을 받아요. 회원, 출석, 입관계약서 관리는 **관리 시작하기**를 누르면 열려요.

* [매니저 웹 열기](https://manager.thisisbjj.com)
* [iPhone 앱 받기](https://apps.apple.com/kr/app/id6759941989)

## 처음 30분 안에 시작하기

1~3단계는 계속 무료예요.

{% stepper %}
{% step %}
### [가입하기](getting-started/login.md)

휴대폰 번호나 카카오, 네이버, 구글 계정으로 가입해요.
{% endstep %}

{% step %}
### [체육관 등록하기](getting-started/gym-registration.md)

종목, 이름, 주소를 넣으면 근처 찾기에 바로 보여요.
{% endstep %}

{% step %}
### [체육관 페이지 꾸미기](getting-started/gym-page-setup.md)

사진, 시간표, 회비를 채우고 체험 받을 수업을 골라요.
{% endstep %}

{% step %}
### [관리 시작하기](getting-started/start-management.md)

누른 날부터 30일 무료예요.
{% endstep %}

{% step %}
### [회원 옮기기](getting-started/import-members.md)

쓰던 엑셀이나 CSV를 올리면 운영팀이 옮겨 드려요.
{% endstep %}

{% step %}
### [출석 키오스크 켜기](attendance/kiosk.md)

태블릿을 두면 회원이 전화번호 뒷 4자리로 출석해요.
{% endstep %}
{% endstepper %}
