# 주짓주짓 매니저 이용 가이드

> 회원, 계약서, 출석, 승급, 매출을 한곳에서. [주짓주짓 매니저](https://manager.thisisbjj.com)와 함께하세요.

---

## 주짓주짓 매니저란?

**주짓주짓 매니저**는 주짓수·태권도를 비롯한 **격투기 체육관**을 위한 관리 서비스입니다.\
전자 계약서, 출석 키오스크, 승급식, 키즈 등·하원 알림, 결제 기록과 매출을 PC·휴대폰 브라우저와 iPhone 앱 **주짓주짓 매니저**에서 씁니다.

{% hint style="success" %}
처음이라면 [**주요 기능 훑어보기**](quick-overview.md)부터 읽어 보세요.
{% endhint %}

---

## 이 가이드의 구성

가이드는 **어느 체육관이든 똑같이 쓰는 기능**과 **종목별로 다른 기능**으로 나뉘어 있습니다.

| 구분 | 내용 | 바로가기 |
|---|---|---|
| **시작하기** | 로그인, 체육관 등록, 사업자 인증, 시작 가이드 | [로그인](getting-started/login.md) |
| **공통 기능** | 회원·회원권·계약서·출석·키즈 등·하원·알림톡·매출·구독 | [홈](dashboard.md) |
| **주짓수 체육관** | 벨트(그랄·키즈 벨트), 승급식 | [주짓수 체육관 운영](jiujitsu/README.md) |
| **태권도 체육관** | 급·품·단 띠 설정, 승급식 | [태권도 체육관 운영](taekwondo/README.md) |

{% hint style="info" %}
종목은 [체육관 등록](getting-started/gym-registration.md)할 때 고릅니다. 고른 종목에 맞춰 벨트·띠 이름, 띠 목록, 계약서 초안이 바뀝니다.
{% endhint %}

### 시작하기

1. [로그인](getting-started/login.md): 휴대폰 번호 또는 카카오·네이버·구글 계정
2. [체육관 등록](getting-started/gym-registration.md): 종목을 고르고 체육관을 찾거나 직접 입력
3. [관리 시작하기](subscription.md): 누른 날부터 관리 기능 30일 무료
4. [시작 가이드](getting-started/setup-checklist.md): 회원권 · 회원 · 첫 출석 3단계
