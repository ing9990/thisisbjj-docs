# 업데이트 소식

주짓주짓 매니저에 새로 생기거나 바뀐 것을 최근 것부터 정리했어요.

## 2026년 11월

### 이용 가이드를 새로 정리했어요 (11월 20일)

가이드 목차를 메뉴 이름이 아니라 하려는 일로 다시 묶었어요. 처음이라면 [처음 30분 안에 시작하기](../README.md)부터 보세요. 옛 주소로 들어와도 새 쪽으로 넘어가요.

### 소개 페이지 새 단장 (11월 19일)

[manager.thisisbjj.com](https://manager.thisisbjj.com) 소개 페이지를 새로 만들었어요. 체육관 홍보는 무료, 관리 기능은 구독 하나로 정리했어요. → [요금과 구독](../billing/subscription.md)

### 매니저 앱 2.0 (11월 16일)

iPhone 앱 「주짓주짓 매니저」가 앱스토어에 나왔어요. 웹과 같은 체육관을 함께 관리해요. 아래 탭은 홈 · 회원 · 문의·체험 · 매출 · 체육관이에요. → [웹과 iPhone 앱](../getting-started/web-and-app.md)

### 문의·체험 (11월 16일)

주짓주짓 앱에서 들어온 체험 신청을 한곳에서 확정·거절하고, 체험 온 사람이 등록했는지까지 표시해요. 이번 달 조회 → 문의 → 체험 신청 → 등록 흐름도 봐요. → [문의·체험 신청 답하기](../new-members/inquiries.md)

### 시간표 (11월 14일~16일)

* 시간표를 수업 종류(일반·키즈부·스파링 등)별로 요일·시간 표에 넣어요. 빈 칸을 눌러 넣고, 요일을 복사하고, 되돌릴 수 있어요.
* 체험 받을 수업은 시간표 칸에서 골라요.
* 수업 시작 시간을 옮기면 잡힌 체험 예약도 함께 옮기고 예약한 사람에게 알려요.

→ [시간표](../attendance/timetable.md) · [체험 수업 받기](../new-members/trial-classes.md)

### 체육관 페이지 (11월 14일)

주짓주짓 앱 근처 찾기에 보이는 체육관 페이지를 웹에서도 꾸며요. 고치는 대로 오른쪽 미리 보기에 바로 보여요. 무료 체험을 받으면 근처 찾기에서 상위 노출돼요. → [체육관 페이지와 근처 찾기](../new-members/gym-page.md)

### 「관리 시작하기」부터 30일 무료 (11월 14일)

* 체육관 등록, 체육관 페이지, 문의·체험 신청 받기는 계속 무료예요.
* 관리 기능은 「관리 시작하기」를 누른 날부터 30일 무료이고, 그 뒤에 구독해요. 카드 등록은 필요 없어요.
* 회원 20명까지 무료였던 기본 플랜은 없어졌어요(11월 2일부터 30일 무료로 바뀜).

→ [④ 관리 시작하기](../getting-started/start-management.md)

### 승급식

* 주짓수 승급식이 IBJJF 나이 기준으로 벨트를 제안하고, 체육관에 맞게 나이를 바꿀 수 있어요(11월 15일).
* 블랙 벨트 이상은 승급 대상으로 추천하지 않아요.
* 태권도의 「승급 심사」도 「승급식」으로 이름을 맞췄어요(11월 16일).

→ [주짓수 승급식](../disciplines/bjj-ceremonies.md) · [태권도 승급식](../disciplines/tkd-ceremonies.md)

### 공지 (주짓주짓 앱)

공지를 주짓주짓 앱 게시판과 푸시로 보내요. 회원 공지와 전체 공지를 고르고, 사진과 맨 위 고정도 넣어요. → [공지 (주짓주짓 앱)](../contracts/notices.md)

### 회원 등록과 결제 기록

* 「오늘 처음 온 회원」과 「이미 다니던 회원」으로 나눠 등록해요. 계약서는 카톡이나 QR로 그 자리에서 받아요. → [회원 등록과 회원 상세](../members/README.md)
* 결제는 쓰던 방식대로 받고 결제 기록만 남겨요. 결제 수단은 카드 · 현금 · 계좌이체예요. → [결제 기록과 이번 달 결제 전](../members/payments.md)
* 쓰던 명단은 엑셀·CSV 파일 그대로 올리면 운영팀이 등록해 드려요. → [⑤ 회원 옮기기](../getting-started/import-members.md)

### 알림톡

* 유료 문자 상품을 없앴어요. 회원 알림은 모두 알림톡으로 가고 따로 비용이 없어요.
* 「오래 안 온 회원 알림」이 생겼어요. → [자동 알림톡](../contracts/auto-messages.md)

### 화면 이름 정리

* 도장 → **체육관**, 대시보드 → **홈**, 연장 → **재등록**, 미납 → **이번 달 결제 전**
* 카톡·문자 메뉴 → **알림톡**, 지도자 서명 → **관장 서명**

### 더 많은 종목

주짓수·태권도에 더해 MMA, 복싱, 무에타이, 킥복싱, 유도, 레슬링 체육관도 등록할 수 있어요. → [② 체육관 등록](../getting-started/gym-registration.md)
