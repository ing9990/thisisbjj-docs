# 자주 묻는 질문

## 요금

### 체육관 등록은 정말 무료인가요? <a href="#free" id="free"></a>

네. 체육관 등록, 체육관 페이지, 주짓주짓 앱 근처 찾기 노출, 문의·체험 신청 받기는 계속 무료예요. 회원·출석·계약서 같은 관리 기능은 「관리 시작하기」를 누른 날부터 30일 무료이고, 그 뒤에 구독해요. → [요금과 구독](../billing/subscription.md)

### 알림톡 비용이 따로 드나요? <a href="#alimtalk-cost" id="alimtalk-cost"></a>

아니요. 계약서 서명 요청, 곧 끝나는 회원 안내, 키즈 등·하원 같은 카카오 알림톡은 건수 제한 없이 따로 돈이 들지 않아요. 회원이 늘어도 알림 비용은 오르지 않아요. → [자동 알림톡](../contracts/auto-messages.md)

### 30일이 지나면 기록이 지워지나요?

아니요. 넣어 둔 회원과 출석 기록은 그대로 남아 언제든 볼 수 있어요. 구독하지 않으면 고치거나 새로 넣을 수만 없어요. 체육관 페이지와 체험 신청은 그대로 무료예요.

### 카드를 등록해야 30일 무료를 쓸 수 있나요?

아니요. 「관리 시작하기」만 누르면 돼요. 카드는 구독할 때 웹에서 등록해요.

### 구독은 앱에서 할 수 있나요?

아니요. 구독 결제와 해지는 웹 [manager.thisisbjj.com](https://manager.thisisbjj.com)에서 해요. 매니저 앱에서는 구독 상태만 봐요.

## 회원과 주짓주짓 앱

### 회원도 앱을 설치해야 하나요? <a href="#member-app" id="member-app"></a>

아니요. 출석은 체육관 태블릿의 출석 키오스크에서 하고, 계약서 서명은 알림톡 링크나 QR로 휴대폰 브라우저에서 해요. 체육관 공지를 푸시로 받으려면 주짓주짓 앱이 필요해요. → [공지 (주짓주짓 앱)](../contracts/notices.md)

### 주짓주짓 매니저와 주짓주짓 앱은 무엇이 다른가요?

주짓주짓 매니저는 관장님이 쓰는 관리 서비스예요. 주짓주짓 앱은 회원이 근처 체육관을 찾고, 체험을 예약하고, 다니는 체육관의 공지를 보는 앱이에요.

### 쓰던 회원 명단은 어떻게 옮기나요?

쓰던 프로그램에서 내려받은 엑셀이나 CSV 파일을 그대로 올려 주세요. 운영팀이 확인하고 회원으로 넣어 드려요. → [⑤ 회원 옮기기](../getting-started/import-members.md)

### 회비도 매니저에서 받나요?

아니요. 회비는 쓰던 카드 단말·계좌이체·현금으로 받고, 매니저에는 결제를 기록만 해요. → [결제 기록과 이번 달 결제 전](../members/payments.md)

### 여러 명의 벨트·띠를 한 번에 바꾸려면요?

승급식을 써요. → [주짓수 승급식](../disciplines/bjj-ceremonies.md) · [태권도 승급식](../disciplines/tkd-ceremonies.md)

## 체육관 등록

### 어떤 체육관이 쓸 수 있나요?

주짓수, MMA, 복싱, 무에타이, 킥복싱, 태권도, 유도, 레슬링 같은 격투기 체육관이면 쓸 수 있어요. 목록에 없는 종목은 「그 외」로 등록해요. → [② 체육관 등록](../getting-started/gym-registration.md)

### 검색에 우리 체육관이 안 나와요.

체육관 검색 화면에서 **찾는 체육관이 없어요, 직접 입력할게요**를 눌러 주소로 등록해요.

### 다른 사람이 우리 체육관을 먼저 등록했어요.

사업자 인증 전이라면 검색 결과에서 **제 체육관이에요**를 누르고 사업자 정보를 넣어요. 운영팀이 확인한 뒤 관장님 계정으로 넘겨 드려요. 이미 다른 관장님이 쓰고 있다면 [카카오톡 채널](https://pf.kakao.com/_NnxmZX)로 연락 주세요.

### 체육관을 여러 개 만들 수 있나요?

한 계정에 체육관 하나예요. 지점이 여러 곳이면 카카오톡 채널로 문의해 주세요.

### 체험 신청이 안 들어와요.

사업자 인증, 근처 찾기에 보이기, 체험 받을 수업이 모두 있어야 체험 예약을 받아요. 매니저 앱 **문의·체험** 탭의 「준비」에서 빠진 것을 확인해요. → [체험 수업 받기](../new-members/trial-classes.md)

## 계약서

### 미성년자도 계약할 수 있나요?

네. 서명할 때 보호자 정보를 넣어요. 넣은 보호자 정보는 키즈 등·하원 알림에도 쓰여요. → [회원이 서명하는 과정](../contracts/signing-flow.md)

### 회원이 서명한 계약서를 다시 보고 싶어 해요.

서명 완료 화면의 **계약서 확인하기**나 [manager.thisisbjj.com/p/contracts](https://manager.thisisbjj.com/p/contracts)에서 이름과 전화번호로 확인하면 볼 수 있어요. → [회원이 서명하는 과정](../contracts/signing-flow.md)

### 계약서 링크가 만료됐어요.

링크는 보낼 때 정한 시간 동안만 열려요. 회원 상세에서 다시 보내 주세요. → [입관계약서 보내기](../contracts/sending.md)

## 출석

### 키오스크 기기가 따로 필요한가요?

아니요. 가지고 있는 태블릿, PC, 휴대폰에서 출석 키오스크를 열어 두면 돼요. → [출석 키오스크](../attendance/kiosk.md)

### 학부모님께 등원 알림을 보내고 싶어요.

회원 상세에 **보호자 연락처**를 넣으면 아이가 출석할 때 등원 알림톡이 자동으로 가요. → [키즈 등·하원](../attendance/kids.md)
