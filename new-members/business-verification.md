# 사업자 인증

사업자 인증은 우리 체육관이 실제로 사업자 등록을 한 곳인지 국세청 정보로 확인하는 일이에요. 체육관 등록과 근처 찾기 노출은 인증 없이도 돼요. 하지만 **체험 예약을 받거나 구독을 시작하려면** 인증이 필요해요.

## 언제 필요한가요

| 하려는 일 | 인증 전 | 인증 뒤 |
| --- | --- | --- |
| 근처 찾기에 보이기 | 보여요 | 보여요 |
| 체험 예약 받기 | 받을 수 없어요 | 받아요. 무료 체험이면 「무료 체험」 배지도 붙어요 |
| 구독 시작 | 할 수 없어요 | 할 수 있어요 → [요금과 구독](../billing/subscription.md) |
| 다른 계정이 먼저 등록한 내 체육관 되찾기 | 인증 정보로 확인해요 | → [② 체육관 등록](../getting-started/gym-registration.md) |

{% hint style="info" %}
예시 · 인증 전 체육관도 주짓주짓 앱 근처 찾기에는 보여요. 다만 체육관 페이지의 체험 예약 버튼은 인증을 마친 뒤에 열려요.
{% endhint %}

## 인증하는 곳

* 웹: **체육관 설정 → 체육관 정보 → 인증하기**
* 웹: **문의·체험**이나 **구독** 화면의 **사업자 인증하기**
* 매니저 앱: 체육관을 새로 등록할 때 이어지는 인증 화면, **문의·체험** 탭 「준비」의 **사업자 인증**

## 인증하는 법

1. 인증 화면을 열어요. 「○○의 사업자등록증에 적힌 그대로 넣으면 국세청 정보로 바로 확인돼요」가 보여요.
2. 아래 칸을 사업자등록증과 **똑같이** 넣어요.
3. **보내기**를 눌러요.

| 칸 | 예시 | 꼭 넣나요 |
| --- | --- | --- |
| 대표자명 | 홍길동 | 네 |
| 사업자등록번호 | 000-00-00000 | 네 |
| 개업연월일 | 사업자등록증에 적힌 날짜 | 네 |
| 연락처 | 010-0000-0000 | 네 |
| 사업자등록증 | JPG, PNG, WEBP (5MB 이하) | 아니요. 국세청 확인이 안 될 때 검토에 써요 |

## 결과

| 결과 | 안내 |
| --- | --- |
| 정보가 맞고 계속 사업 중 | 바로 인증이 끝나요. 「사업자 인증을 마쳤어요」 |
| 휴업·폐업 | 인증되지 않아요. 사업자 상태를 확인해 주세요 |
| 정보가 맞지 않음 | 사업자등록번호·대표자명·개업연월일을 등록증과 똑같이 다시 넣어 주세요 |
| 맞지 않지만 등록증을 함께 올림 | 운영팀이 등록증을 보고 검토해요. 보통 **영업일 하루** 안에 끝나요 |

검토가 끝나면 알림톡으로 알려 드려요. 반려되면 사유도 알림톡으로 가요.

{% hint style="success" %}
국세청 확인이 안 될 때를 대비해 사업자등록증을 함께 올려 두면 운영팀 검토로 바로 이어져요.
{% endhint %}

## 인증 상태 보기

**체육관 설정 → 체육관 정보**의 사업자 인증 옆에 표시돼요.

| 표시 | 뜻 |
| --- | --- |
| 인증 완료 | 인증이 끝났어요 |
| 검토 중 | 운영팀이 확인하고 있어요. 「검토가 끝나면 체험 예약을 받아요」 |
| 인증 전 | 아직 인증하지 않았어요. **인증하기**를 눌러요 |
